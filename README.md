# Змейка для iPhone 🐍

Нативная игра на SwiftUI. Готовый `.ipa` собирается автоматически в облаке
(GitHub Actions, бесплатный macOS-раннер) — Mac и платный Apple Developer не нужны.

## Что внутри

- `SnakeGame/` — исходники игры (SwiftUI, iOS 15+)
- `project.yml` — описание проекта для XcodeGen (проект `.xcodeproj` создаётся при сборке)
- `.github/workflows/build-ipa.yml` — автоматическая сборка неподписанного `.ipa`

Управление: свайпы по полю. Счёт и рекорд (сохраняется), пауза, ускорение по мере роста.

---

## Шаг 1. Загрузить проект на GitHub

1. Зарегистрируйся на https://github.com (если ещё нет аккаунта).
2. Нажми **New repository** → имя, например `snake-game` → **Create repository**.
3. На странице пустого репозитория нажми ссылку **uploading an existing file**.
4. Перетащи в окно браузера **всё содержимое этой папки** (включая папку `.github` —
   она обязательна, именно она запускает сборку!).
   Важно: сохраняй структуру папок, перетаскивай именно папки целиком.
5. Нажми **Commit changes**.

## Шаг 2. Дождаться сборки

1. Открой вкладку **Actions** в репозитории.
2. Там появится запуск **Build IPA** (если не стартовал сам — выбери его слева и
   нажми **Run workflow**).
3. Сборка занимает ~3–6 минут. Зелёная галочка = готово.
4. Открой завершённый запуск → внизу раздел **Artifacts** → скачай **SnakeGame-ipa**.
5. Распакуй скачанный zip — внутри лежит `SnakeGame.ipa`.

## Шаг 3. Установить на iPhone (Windows)

Проще всего через **Sideloadly** (бесплатно):

1. Скачай Sideloadly с https://sideloadly.io и установи.
2. Установи **iTunes с сайта Apple** (НЕ из Microsoft Store!) — он нужен для
   драйверов устройства. Если iTunes уже стоит из Store — удали и поставь версию
   с apple.com/itunes.
3. Подключи iPhone кабелем, разблокируй, нажми «Доверять этому компьютеру».
4. В Sideloadly перетащи `SnakeGame.ipa` в окно, выбери свой iPhone.
5. Введи свой обычный Apple ID (бесплатный, платить не нужно) → **Start**.
   Пароль уходит только на серверы Apple, но для спокойствия можно завести
   отдельный Apple ID для сайдлоадинга.

Альтернатива: **AltStore** (altstore.io) — умеет автоматически продлевать подпись
по Wi-Fi, пока AltServer запущен на компьютере.

## Шаг 4. Запустить на iPhone

1. **iOS 16+**: Настройки → Конфиденциальность и безопасность → Режим разработчика
   → включить → перезагрузка.
2. Настройки → Основные → VPN и управление устройством → выбери свой Apple ID
   → **Доверять**.
3. Запускай «Змейку» с домашнего экрана 🎮

## ⚠️ Ограничения бесплатного Apple ID

- Подпись действует **7 дней** — потом приложение перестанет открываться.
  Лечится повторной установкой через Sideloadly (данные сохраняются) или
  автопродлением через AltStore.
- Одновременно максимум **3 приложения**, установленных таким способом.
- Это ограничения Apple, не сборки.

## Кастомизация

- Имя приложения: `CFBundleDisplayName` в `project.yml`.
- Bundle ID: `PRODUCT_BUNDLE_IDENTIFIER` в `project.yml`.
- Размер поля, скорость: константы `cols`, `rows` и `tickInterval` в `GameView.swift`.

Если сборка в Actions упала — открой лог упавшего шага и пришли его, разберёмся.
